# External Data

Raw/bulk datasets, model weights and private personal/market/health archives remain outside Git. Commit schemas, generation code and sanitized manifests/checksums instead. Store no credentials, signed URLs or private absolute paths here.

Use MANIFEST.example.yaml as a template. Replace placeholder dates/identity with actual provenance before using it for an experiment. A manifest does not establish redistribution rights or data quality. Tiny synthetic fixtures may be committed after review; document their schema, size and expected results.
