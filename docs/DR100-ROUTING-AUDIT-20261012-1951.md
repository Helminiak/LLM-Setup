## Proposed change (NOT YET APPLIED)

After exiting the Hermes interactive session, run the [GitHub routing helper](../scripts/dr100-hermes-gpu-route.sh) with `--apply`. The helper backs up the existing user `config.yaml` before setting these keys:

```yaml
delegation:
  provider: lmstudio
  model: qwen3.8-27b-coder390-efficientthink-opus5.5-gpt6astra-grok4.7-dsv4pro-k3-sft-rloo-ninfer@q6_k

  max_spawn_depth: 1
  fallback_providers: []
```

`model.default`, `model.provider`, and compression stay unchanged. **Do not put API credentials into GitHub.** The launcher reads local credentials and uses `LM_API_KEY`. Automatic child cloud fallback is disabled to expose rather than conceal local worker failure. This is routing configuration, not a successful delegation test.
